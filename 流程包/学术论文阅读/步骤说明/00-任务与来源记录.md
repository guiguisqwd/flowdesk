# 步骤 00：确定任务、收集材料、建立来源记录

**输入：**论文全文文字版（用「论文转文字」从 PDF 转出，每页以「=== 第 N 页 ===」开头，文件开头写明哪些页没转出文字）；可选的图表截图、补充材料、研究方案、注册记录、统计分析计划，以及用户的重点问题。

**要做的事：**

- 记录论文身份和材料种类，确认手头有哪些全文、附件和外部资料。
- 给每份材料一个来源标识（S1、S2…），记下文件名和页数；后面所有步骤都用这个标识加页码引用原文。
- 按「=== 第 N 页 ===」标记确认页码；记录没转出文字（扫描页）、阅读顺序可能错乱（多栏、表格）的页面。
- 把“文中提到但尚未取得的材料”列出来。
- 没有重点问题时，以“理解作者如何从数据走到具体结论”为默认任务。

**必要产出：**

| 产出 | 必须包含 |
|---|---|
| 阅读任务 | 目的、重点问题、范围 |
| 文献身份记录 | 标题；作者、年份、期刊、DOI 等以实际取得信息为准 |
| 来源清单 | 来源标识、文件名、页数、材料类型；可用时附来源链接 |
| 解析与覆盖记录 | 总页数、哪些页有文字、哪些页没转出文字或顺序可疑 |
| 材料缺口 | 缺哪份材料、影响哪个问题、下一步如何补齐 |

**验收：**来源可区分；任何覆盖声明都有依据。文本提取成功、文本被提交给模型、模型完成科学核对，是三件不同的事。图内文字或数据可能没有进入文本提取结果。
