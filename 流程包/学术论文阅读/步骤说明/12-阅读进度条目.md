# 步骤 12：写一条阅读进度记录

**输入：**完整阅读包、你的审阅决定。

**要做的事：**把这篇论文读到哪、结论是什么、还欠什么，整理成一条固定格式的进度记录。它会被「论文阅读工具/更新阅读进度」收集到你电脑上的「文稿/论文阅读进度」文件夹里，Codex 能直接读，也能一键放进 Mac 的「提醒事项」。

**必要产出：**一个 JSON 文件「阅读进度条目」，字段固定如下（没有的信息写空字符串或空数组，不要编）：

```json
{
  "记录类型": "论文阅读进度",
  "论文": {"标题": "", "短标题": "", "作者": "", "年份": "", "期刊": "", "DOI": ""},
  "日期": "YYYY-MM-DD",
  "状态": "已读完 / 读了一部分 / 暂停",
  "采用": "采用 / 暂不采用 / 部分采用",
  "一句话结论": "",
  "我的评价": "",
  "主要结论": [{"编号": "C01", "结论": "", "支持范围": "", "证据强度": "强 / 中 / 弱 / 不清楚"}],
  "仍有缺口": [{"缺口": "", "影响哪条结论": "", "怎么补": ""}],
  "要回原文看的": [""],
  "下一步": [{"要做的事": "", "截止日期": "YYYY-MM-DD 或空"}],
  "标签": [""]
}
```

**做法要点：**

- 「状态」「采用」「我的评价」「下一步」以你在步骤 11 写的为准，不替你决定。
- 「主要结论」最多 5 条，按阅读包里的结论编号。
- 「下一步」里每一件事会变成一条提醒，写成能直接去做的一句话。
- 「短标题」用中文写，十几个字以内，格式“第一作者 年份 主题”，例如“Lunkes 2026 Pilates 腹部放松”。它会用在进度总表和提醒事项里。
- 「日期」写今天。

**验收：**是合法 JSON；含 `"记录类型": "论文阅读进度"`；论文标题不为空；字段名与上面完全一致；内容都能在阅读包或你的审阅决定里找到。
