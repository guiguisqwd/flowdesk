# 步骤 04：拆清变量与测量

**输入：**方法、量表或仪器说明、变量定义、数据编码及表格脚注。

**必要产出：变量与测量字典。**

| 字段 | 必须说明 |
|---|---|
| 变量名称与分析归属 | 哪个分析用到它 |
| 在该分析中的角色 | 暴露、干预、结局、协变量、潜在中介、分层或其他角色 |
| 实际测量对象 | 理论概念具体用什么可观察量表示 |
| 测量方法 | 自报、问卷、量表、仪器、实验室检测、行政记录等 |
| 时间 | 测量时点、回忆窗口、观察时长 |
| 单位与编码 | 原始单位、转换、阈值、分组、参照组、方向 |
| 缺失与测量限制 | 原文报告的处理及与结论相关的限制 |
| 来源定位 | 具体页、段、表或补充材料 |

**验收：**量表得分、自报行为、仪器测量和生理过程要按实际内容表述。同一变量在不同分析中角色可能不同，不能固定成一个全局角色。干预口令或行为要求不能直接作为实际执行或生理变化已发生的证据。
