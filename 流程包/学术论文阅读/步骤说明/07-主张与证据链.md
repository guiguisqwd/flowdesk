# 步骤 07：拆分作者主张并连接证据

**输入：**作者结果与讨论中的主张，以及已经整理的数据、样本、变量、方法和结果。

**必要产出一：主张清单。**

| 字段 | 内容 |
|---|---|
| 标识与短标题 | 可以被单独引用和审阅的一条结论 |
| 作者主张 | 保留其含义、范围和语气强度 |
| 当前证据支持范围 | 支持到哪些对象、条件、比较、结局和时间；仍有何不确定性 |
| 对应证据 | 支撑它的单元及原文位置 |
| 缺口 | 哪个推导环节尚不能接上，影响多大 |

**必要产出二：每条主张的证据关系。**

```text
数据来源 → 样本形成 → 变量与测量 → 分析方法 → 实际结果 → 具体结论
```

这是一条检查路径，不要求把所有论文强行排成单一路径。多个结论可以共享样本、变量或方法；一条结论也可能依靠多个结果。共享内容保留同一标识，各条关系说明自己的用途。

**每个证据单元都必须说明：**它是什么、输入是什么、做了什么处理或论证、输出什么、支持哪条主张、证据状态、原文位置、支持范围与缺口。

**关系分为四类：**

| 关系 | 含义 |
|---|---|
| 数据处理 | 来源、筛选、测量或编码怎样得到分析输入 |
| 统计估计 | 方法怎样从输入得到估计结果 |
| 证据支持 | 结果怎样支持某条有范围限制的主张 |
| 机制假说 | 作者提出的潜在解释关系，不能画成已成立的因果路径 |

**验收：**不能只因为两个内容在页面上相邻，就声称它们有推导关系；不能用一项研究的背景介绍替代支持当前结论的实际结果。
