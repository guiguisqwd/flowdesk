# 步骤 08：单独检查机制与推断层级

**输入：**生物学或行为机制陈述、相关测量、机制分析、讨论及引用文献。

**必要产出：机制与证据状态表。**

| 状态 | 应怎样表述 |
|---|---|
| 作者报告 | 原文说了什么，尚需看它依据什么 |
| 作者假说 | 作者提出一种解释或预期 |
| 实际测量 | 作者报告本文测量了某个变量，能够定位对应说明 |
| 实际检验 | 作者报告本文开展了某项关系或差异分析，能够定位对应方法或结果 |
| 引用外部研究 | 依据来自别的研究；未取得原文时注明未独立核对 |
| 分析者推断 | 阅读者或 AI 的解释，需要单独标明 |
| 未报告 | 当前已读材料没有提供这项信息 |

每个机制条目还应写：对应哪条主张、测量的是哪一层过程、时间顺序是否建立、是否做了中介等分析、该分析本身能支持什么、仍缺哪些检验。

“实际测量”和“实际检验”表示从论文中确认了相应报告内容，不表示已经独立核实实验或分析确实按所述执行。

**验收：**测量一个标志物、发现统计关系、完成中介分析、验证因果机制必须分开。一个机制在本文没有被检验，不等于机制被证明错误；两项变量分别变化，也不自动证明其中一个导致另一个。
