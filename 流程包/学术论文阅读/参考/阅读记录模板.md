# 一篇论文的完整阅读记录模板

以下模板可用于人工审阅或后续文字导出；字段必须依据材料填写。

```markdown
# [论文标题] 阅读记录

## 阅读任务与版本
- 阅读目的：
- 重点问题：
- 文献身份：
- 来源与材料：
- 当前阶段、版本、人工修改与采用状态：
- 解析覆盖、分析覆盖与未核对内容：

## 01 为何研究
[已知背景、具体缺口、作者提出的研究理由]

## 02 研究问题 / 假设
[研究对象、暴露或干预、比较、结局、时间]
[明确提出的假设；没有则写未明确提出]

## 03 如何研究
[实际设计、来源、样本、测量和主要方法]

## 04 实际结果
[核心估计、单位、不确定性及对应分析]

## 05 作者结论
[保留作者解释和语气强度]

## 分析目录
[逐项列主要、次要、探索、敏感性及机制分析]

## 数据、样本与人数
[来源、纳排、测量人数、分析人数、缺失处理、原文位置]

## 变量与测量
[每项变量的角色、定义、工具、编码、单位、时点和限制]

## 方法
[每个方法的输入、处理、输出、实际用途、关键假设及出处]

## 结果
[逐分析列人群、比较、结局、时点、估计、区间、分母与出处]

## 结论与证据链
### 结论 C01：[短标题]
- 作者主张：
- 当前证据支持范围：
- 对应数据、样本、测量、方法和结果：
- 各关系是什么，为什么能连接：
- 原文位置：
- 仍缺什么，对主张有什么影响：
[按实际结论数量重复]

## 机制与推断状态
[区分假说、实测、检验、外部引用与分析者推断]

## 缺口与报告不一致
[具体对象、各处原文、影响、状态和下一步]

## 审查与程序检查
[AI 审查发现；程序检查范围与诊断；人工核对记录]

## 独立问答与外部查证
[仅记录实际发生的查询，注明绑定版本和是否明确纳入]

## 人工决定与版本变化
[批注、修改、重读、新材料、采用与保留缺口]

## 来源索引
[原文件、来源标识、页段行、短引文、图表及附件]
```

## 完成判定

一份可交付的阅读记录应能通过以下内容检查：

- [ ] 研究问题和设计有依据，假设没有被补造。
- [ ] 初步阅读与已回原文审查的状态分开。
- [ ] 主要结论都有对应证据或明确缺口。
- [ ] 人群、比较、结局、时间和数值对齐。
- [ ] 数据来源与样本形成过程可追溯。
- [ ] 测量人数与分析人数分开，缺失处理有记录。
- [ ] 关键变量的测量、单位、编码和角色明确。
- [ ] 方法说明对应本文实际输入、处理和输出。
- [ ] 效应大小、不确定性与实际意义分别讨论。
- [ ] 作者主张与当前可支持范围并列保留。
- [ ] 机制假说、测量、统计检验与因果验证没有混同。
- [ ] 共享证据与多条分析关系没有被强行压成单链。
- [ ] 原文引文和定位可回查；不确定定位明确标出。
- [ ] 表格、图和 OCR 的未核对部分被保留。
- [ ] 报告不一致保留各处原文，没有悄悄改写。
- [ ] 未取得、未识别、未报告和已知未执行被区分。
- [ ] 程序检查与科学审查的范围清楚。
- [ ] 问答和外部检索没有默默改变正文。
- [ ] 人工修改、新来源和旧版本均可追溯。
- [ ] 最终采用状态如实记录，仍有的缺口没有被隐藏。

这些检查中，有的可以由程序完成，有的需要 AI 或人回到原文判断。允许交付带缺口的阅读记录，但不能把未完成核查的部分写成已经确认。
