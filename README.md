# Flowdesk 试用版

把一份做事的说明（skill、文档，或者一句"我要做什么"）交给 AI，AI 把它拆成一步一步的流程。每一步交出一样东西，你可以一步一步看、通过或打回，哪一步不满意就只重做那一步。

> 这是一个试用版，还在开发中。欢迎试用，把遇到的问题和建议告诉我们。

## 下载

**[点这里下载试用版（ZIP）](https://github.com/guiguisqwd/flowdesk/archive/refs/heads/main.zip)**

## 需要什么

- 一台 Mac（这个版本只支持 Mac）。
- 网络（第一次安装要下载东西）。
- Codex 桌面版，并用 ChatGPT 账号登录。Flowdesk 用它来调用 AI，费用和次数算在你自己的 ChatGPT 账号上。没装的话，安装程序会帮你打开下载页。

## 安装（大约 3–10 分钟）

1. 解压下载的 ZIP（Safari 通常会自动解压）。
2. 双击里面的「安装Flowdesk.command」。
   如果 Mac 说"无法打开，因为无法验证开发者"：打开「系统设置 → 隐私与安全性」，往下拉，点「仍要打开」，再双击一次。
3. 会弹出一个「终端」窗口，按里面的提示做，直到它说「装好了」。
4. 浏览器会打开 Flowdesk。以后点 Dock 上的 Flowdesk 图标（米色、三个点）就能打开。

## 第一次试，可以这样做

1. 点「新建第一个工作台」，起个名字，点「创建工作台」。
2. 会弹出「导入原始材料」。选「从一句需求开始」，写一句你想做的事，例如"每周把读过的文章整理成一份读书笔记"。也可以导入你手上的一份说明文档、skill 文件夹或 ZIP。
3. AI 会先列出步骤骨架，然后停下来等你看。看完觉得可以，就让它继续补全每一步。
4. 回到首页（产出链），点「开始第一条」，让流程真的跑一次。
5. 点进某一步，看它交出的东西：满意就「通过」，不满意就「打回」并写一句原因。想改这一步，就在右边的对话框里直接说。

## 反馈

两种方式，选一种就行：

- **有 GitHub 账号**：[在这里提一条反馈](https://github.com/guiguisqwd/flowdesk/issues/new?template=试用反馈.md)。
- **没有 GitHub 账号**：填写下载包里的「反馈表.txt」，发回给邀请你的人。

截图非常有用。出错时，请附上日志文件：在「访达」里按 ⌘⇧G，粘贴 `~/Library/Logs/Flowdesk.log`，回车。

## 你的东西放在哪

- Flowdesk 程序和你做的项目都在你个人文件夹下的「Flowdesk」文件夹（`~/Flowdesk`）。
- 你的项目只存在你自己的电脑上，不会自动发给任何人。AI 处理内容时，内容会经过你自己登录的 Codex（ChatGPT）。

## 卸载

把「应用程序」里的 Flowdesk 和个人文件夹下的「Flowdesk」文件夹拖进废纸篓即可（项目也会一起删掉，需要的话先备份 `~/Flowdesk/projects`）。
